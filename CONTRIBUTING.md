# Contributing

Thanks for your interest in Local AI Automation Kit!

## Getting started

You do not need to be an expert to contribute. Documentation improvements, examples, workflow ideas, bug reports, and small fixes are welcome.

## Before opening a pull request

1. Explain what you changed.
2. Explain why the change is useful.
3. Keep changes small and focused.
4. Do not include secrets, API keys, passwords, or private data.

## Good first contributions

- Improve documentation
- Add an n8n workflow example
- Fix a typo
- Add a troubleshooting note
- Add a reproducible example
